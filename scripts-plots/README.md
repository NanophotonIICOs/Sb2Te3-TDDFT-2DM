# Plotting Scripts

This folder contains the scripts used to reproduce the figures presented in the manuscript:  
*"Linear optical response of monolayer Sb2Te3 under uniaxial strain assessed by Time-Dependent Density Functional Theory"* (2025).

---

## Tools

- **Julia + PGFPlotsX.jl**  
  Figures were generated in [Julia](https://julialang.org/) using [PGFPlotsX.jl](https://github.com/JuliaTeX/PGFPlotsX.jl), a wrapper around the LaTeX/TikZ **PGFPlots** library.  
  This ensures publication-quality vector graphics consistent with LaTeX typesetting.

---

## Notes
- **No generative AI tools** were used.  
- The scripts reproduce the band structures, dielectric functions, and optical spectra as reported in the article.
